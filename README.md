# Zomato User Behavior Segmentation

## 📌 Project Overview

This project focuses on analyzing and segmenting Zomato users based on their behavioral patterns. The goal is to identify distinct customer groups that can help businesses better understand user preferences and behavior.

The project uses **Exploratory Data Analysis (EDA), Principal Component Analysis (PCA), and K-Means Clustering** to discover meaningful customer segments.

## 🛠️ Technologies & Tools

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- PCA
- K-Means Clustering
- Jupyter Notebook

## 🔍 Key Steps

- Data cleaning and preprocessing
- Exploratory Data Analysis
- Outlier analysis
- Feature selection and scaling
- Dimensionality reduction using PCA
- Customer segmentation using K-Means
- Cluster evaluation and visualization
- Interpretation of user segments

## 🎯 Objective

The main objective is to identify different Zomato user behavior patterns and create meaningful customer segments that can support data-driven business and marketing decisions.

## 📊 Project Type

**Unsupervised Machine Learning | Customer Segmentation | Data Analytics**
